# Вторая часть дипломного проекта QA-java

API-тесты на Java для учебного проекта Яндекс Практикума
[Stellar Burgers](https://stellarburgers.nomoreparties.site)

### Стек технологий:
- Java 11
- Maven 3.9.0
- JUnit 4.13.2
- RestAssured 5.4.0
- Allure 2.35.1
- GSON 2.8.9

### Задание - протестировать эндпоинты API
#### 1. Создание пользователя
- создать уникального пользователя;
- создать пользователя, который уже зарегистрирован;
- создать пользователя и не заполнить одно из обязательных полей.
#### 2. Логин пользователя
- вход под существующим пользователем;
- вход с неверным логином и паролем.
#### 3. Создание заказа
- с авторизацией;
- без авторизации;
- с ингредиентами;
- без ингредиентов;
- с неверным хешем ингредиентов.
